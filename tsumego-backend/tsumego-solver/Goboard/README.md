# Goboard - C++ Go Game Logic Library

囲碁のルール、盤面状態、ゲーム進行を厳密かつ高速に管理するC++ライブラリです。
KataGoなどのモダンな囲碁AIの内部実装でも用いられる、`StoneString`（石の連）によるダメの差分更新と、Zobrist Hashingを利用した高速な盤面ハッシュ・コウ判定を採用しています。

```text
│   ├── Goboard.hpp        # 盤面・ゲーム進行管理クラス

    ├── CMakeLists.txt     # テスト用のビルド設定

```

## クラスの役割と設計

本ライブラリは、主に以下の3つのコンポーネントから構成されています。

### 1. `StoneString` クラス
盤上で上下左右に連結した同色の石の集団（連）を管理するデータ構造です。
- **ダメの管理**: 自身の連が持っているダメ（空点）を座標のSetとして保持し、重複なく正確に管理します。
- **高速な状態更新**: 隣接する敵の `StoneString` への参照を保持しています。これにより、石を置いた時のダメの減少や、石が取られた時の周囲の石のダメ回復処理を局所的かつ高速に計算します。
- **オブジェクトプール**: メモリ割り当てのオーバーヘッドを防ぐため、インスタンスは `Goboard` クラス内部のプールで管理・再利用されます。

### 2. `Goboard` クラス
ゲーム全体の進行とルールの適用を管理するメインクラスです。
- **盤面データ**: 各交点から所属する `StoneString` を $\mathcal{O}(1)$ で参照できる配列（ポインタのリスト）を保持しています。
- **着手処理 (`move`)**: 石の配置、`StoneString` のマージ・分割（取り除き）、敵石の捕獲処理を行います。
- **ルール判定 (`is_playable`)**: 自殺手やコウに基づく着手禁止点を厳密に判定します。
- **ゲーム進行**: パス（着手放棄）をサポートし、2連続パスによる終局判定（`is_game_over`）を行います。

### 3. `ZobristTable` クラス
盤面の状態を64bitの整数値（ハッシュ値）で表現するための乱数テーブルを管理します。
- **高速な差分更新**: 石が置かれたり取られたりする度に XOR 演算を行うだけで、盤面全体のハッシュ値を $\mathcal{O}(1)$ で算出します。
- **コウ・スーパーコウ判定**: `Goboard` はこのハッシュ値の履歴を保持し、過去の盤面と同一状態になる着手（コウ）を禁止します。

## 主な機能
- 任意の盤面サイズ（長方形碁盤にも対応可能）
- 着手禁止点（既に石がある、自殺手、コウ）の厳密な判定
- パス機能と連続パスによる終局判定
- スーパーコウルールのON/OFF設定
